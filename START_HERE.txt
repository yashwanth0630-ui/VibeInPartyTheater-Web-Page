📹 ADDING YOUR VIDEOS:

For VibeInParty:
→ Edit: party-room-app/src/pages/VibeinpartyLanding.jsx
→ Line: 32
→ Replace: <source src="VIDEO_URL" type="video/mp4" />

For Neerala's Kitchen:
→ Edit: party-room-app/src/pages/NeeralasLanding.jsx
→ Line: 32
→ Replace: <source src="NEERALA_LOOPING_MOV_URL" type="video/mp4" />

Need to convert MOV to MP4?
$ ffmpeg -i NeeralasLooping.MOV -c:v libx264 -c:a aac output.mp4

🚨 COMMON ISSUES:

"npm install fails"
→ Make sure you have Node.js 20+ installed
→ Run: node --version

"Videos not playing"
→ Use MP4 format (not MOV)
→ Check video URL is correct
→ Ensure video has proper CORS headers

"Mobile layout looks wrong"
→ Clear browser cache
→ Test in incognito mode
→ Check media queries in CSS files

"Console errors"
→ Check file paths are correct
→ Verify all imports match
→ Make sure dependencies installed
